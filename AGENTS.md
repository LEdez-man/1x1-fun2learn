# AGENTS.md

## Language style

| Place | Language |
| --- | --- |
| UI texts, `spec.md`, `README.md`, `CHANGELOG.md`, code comments | German |
| Identifiers (`spawnWave`, `_pruneHiddenSpots`) | English |
| Domain terms in labels and data (`Königsaufgaben`, `Lernraster`) | German, terms from `spec.md` §3 |

- Write real umlauts (ä, ö, ü, ß); file names stay ASCII (`schnee-daemmerung.png`).
- Typography: `×`, `–`, „…“.
- UI texts are short imperatives a primary-school child understands: `Los geht's`, `Auswahl leeren`.
- Docs are impersonal: no "Sie", no "wir".
- `CHANGELOG.md` uses the German Keep a Changelog headings (`Hinzugefügt`, `Geändert`, `Behoben`), one entry per change visible to players or teachers.
